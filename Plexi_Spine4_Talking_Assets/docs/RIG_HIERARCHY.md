# Plexi – Spine 4.x Rig Hierarchy

Generated by `scripts/build_skeleton.mjs` into `spine/Plexi_skeleton.json` (Spine JSON skeleton data for **Spine Editor → Import Data**). Head-and-shoulders only; no body rig.

Conventions
* `_L` = **screen-left** (the character's right), `_R` = screen-right. Same for files, slots and bones.
* Units are canvas pixels of the 1200 × 1408 working canvas (original art × 4). Spine's origin is the bottom-centre of that canvas, y up.
* Bone-local offsets in the JSON are computed from `artwork/manifest.json`; never edit them by hand – rerun the script.

## Bones

```
root
└─ body                      chest pivot; breathing scale
   ├─ drawstring_L           eyelet pivot, rotation -90 so +x points down the string
   ├─ drawstring_R
   └─ neck                   base of the neck
      └─ head                pivot at the top of the neck (chin height); tilt / nod
         ├─ hair_front       hair mass pivot; secondary lag
         ├─ eye_L            iris + pupil translate (gaze)
         ├─ eye_R
         ├─ eyelid_upper_L   translate -y to close
         ├─ eyelid_lower_L   translate +y to squint
         ├─ eyelid_upper_R
         ├─ eyelid_lower_R
         ├─ brow_L           translate / rotate
         ├─ brow_R
         └─ mouth            all mouth attachments; translate/scale for emphasis
```

No `jaw` bone: the chin cannot be separated from the flattened face (see `docs/ARTWORK_AUDIT.md`). Mouth opening is done by attachment swaps.

All attachments are **region attachments** at scale 1, rotation 0; their `x/y` are the image centre relative to the bone. The setup pose reproduces the original artwork (`qa/composite_rest.png`, `qa/preview/setup.png`).

## Eye rig

* **Blink**: `eyelid_upper_*` translate y = −`openHeight` (≈ −57 px) closes the eye; the clipping polygon keeps the lid inside the opening so closure is clean. `eyelid_lower_*` translate +y ≈ 18 % of the opening adds a natural squeeze.
* **Squint / relaxed**: lower lid +15–25 %, upper lid −10–15 %.
* **Wide**: upper lid +3 px (the lid is already above the opening, so "wide" is mostly brow + a tiny pupil move).
* **Gaze**: `eye_*` translate. Safe range ≈ **±16 px x, ±5 px y**; beyond that the iris is clipped by the opening (acts like a real eye, never escapes the white). Pupil and iris share the bone, so they stay registered; animate `pupil_*` scale for dilation.

## Brows

Independent bones at each brow's centroid. Raise = translate +y (5–11 px), worry = rotate inner ends up (`brow_L` +rot, `brow_R` −rot), anger = the opposite. Keep translations under ~12 px so the brow stays on the forehead.

## Mouth

Attachment swaps in slot `mouth` (see `docs/LIP_SYNC_GUIDE.md`). Every mouth image is built on the same footprint around the measured mouth centre, so swaps never slide or rescale. The `mouth` bone can add ±3 px y bounce / 1.03 scale on open visemes for emphasis. Part slots 20–23 let an animator assemble a custom mouth from interior/teeth/tongue if a viseme is missing.

## Animations

| Name | Length | Loop | What it does / how to use |
| --- | --- | --- | --- |
| `idle` | 4.0 s | yes | breathing (body scale), ±1° head, hair lag, drawstring sway. No blinks – play `blink` on another track. |
| `blink`, `blink_L`, `blink_R` | 0.25 s | no | close 0.08 s, hold 0.05 s, open 0.12 s. Trigger every 2–6 s on track 1. |
| `listening` | 6.0 s | yes | relaxed smile, slow tilt, gaze shift, two blinks baked in. |
| `talking` | 2.4 s | yes | demo viseme sequence + head emphasis. **Placeholder** – real dialogue uses cue-driven swaps. |
| `happy` | pose | – | brows up, lower lids squint, smile. Cross-fade with a 0.2–0.3 s mix. |
| `surprised` | pose | – | brows high, lids wide, `mouth_open`. |
| `concerned` | pose | – | inner brows up, upper lids slightly down, `mouth_rest`. |
| `thinking` | pose | – | gaze up-right, asymmetric brows, head tilt, `mouth_rest`. |
| `visemes/<GROUP>` | 1 frame | – | sets the mouth attachment only; for runtime lip-sync on a dedicated track. |
| `lipsync/*` | per line | no | generated from cue files by `scripts/cues_to_animation.mjs`. |

Suggested tracks: 0 = `idle`/`listening`/expressions, 1 = `blink`, 2 = `visemes/*` or `lipsync/*`.

## Extending

* Separate drawstrings: split `hood_drawstrings.png` by x in `prepare_artwork.mjs` and add two slots.
* True jaw: paint a chin/jaw layer, add `jaw` under `head`, move the lower-lip part of each mouth onto it.
* Mesh deformation (cheek bulge on smiles) is intentionally not used; add it in Spine only if an artist supplies repainted mouths.
